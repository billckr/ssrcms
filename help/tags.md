# Tags

Tags are flexible labels that connect posts about the same subject. Unlike categories, they are
usually used for specific topics or details, and a post can have several. Visitors may use tag
archive pages to find other published posts with the same tag.

- [Viewing and sorting tags](#viewing-tags)
- [Adding a tag](#adding-tags)
- [Using and deleting tags](#using-tags)

<a id="viewing-tags"></a>
## Viewing and sorting tags

The table shows each tag's **Name**, **Slug**, and number of associated **Posts**. Select any of
those column headings to sort by it; select the same heading again to reverse the order.

The post count describes associations, not necessarily the number of publicly visible posts. A
tag can also be attached to drafts or other non-public content.

<a id="adding-tags"></a>
## Adding a tag

1. Enter the visitor-facing **Name** in the Add Tag panel.
2. Review the generated **Slug**, or replace it with your own.
3. Select Add Tag.

The slug is the URL-safe identifier used in paths such as `/tag/product-news`. It must contain
only lowercase letters, numbers, and hyphens. Spaces are changed to hyphens, and leaving the field
blank generates the slug from the name. Names and slugs must be unique within the site.

After creating the tag, open a post and select it in the **Tags** section to attach it. There is no
rename or edit action on the Tags page currently; create the intended replacement and update the
affected posts if a term needs to change.

<a id="using-tags"></a>
## Using and deleting tags

Select the trash button and confirm to delete a tag. This removes the tag and its associations; it
does not delete the posts that used it. Deletion is immediate, so check the Posts count and update
affected content first when the public tag archive or its URL still matters.
